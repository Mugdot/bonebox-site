FORUM

Where to talk about the game, report a bug, or tell us which job should be a character next.

Report a bug or suggest something

The game's public board is on GitHub. You need a free GitHub account to post; anyone can read.

Open the board

A good bug report says three things: which character you were playing, where you were (dungeon and level, or which boss), and what happened against what you expected. A screenshot helps more than a paragraph.

On Steam

When the Steam page opens, its Community Hub will have discussions, screenshots and guides, and that will be the busiest place to talk about the game.

House rules

  • Be decent to each other. Argue about characters, not about people.
  • Mark spoilers. Some of this game is meant to be found, not read about.
  • No personal information, yours or anyone else's.
  • One report per problem. Check whether it is already there first.

Before you post

The manual covers controls and how a run works. If the game is flashing more than you are comfortable with, the health page explains how to turn that down.
